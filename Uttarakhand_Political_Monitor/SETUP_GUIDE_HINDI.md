# उत्तराखंड व राजनीतिक मीडिया मॉनिटर (Setup & Automation Guide)

यह सिस्टम **उत्तराखंड, हिमाचल प्रदेश और नेशनल** के सभी राजनीतिक मुद्दों, विरोध-प्रदर्शनों, पेपर लीक, भू-कानून, मूल निवास व सियासी विवादों को 24x7 बिना कुछ स्किप किए ट्रैक करता है।

---

## 💻 1. लोकल कंप्यूटर पर तुरंत कैसे देखें?

1. **लाइव डैशबोर्ड खोलें:**
   - फ़ोल्डर में मौजूद [`dashboard.html`](dashboard.html) पर डबल क्लिक करें या [`start_dashboard.bat`](start_dashboard.bat) चलाएं।
   - यह ब्राउज़र में लाइव डैशबोर्ड खोल देगा जहाँ सभी कार्ड्स दिखेंगे। किसी भी कार्ड पर क्लिक करने पर:
     - **मुद्दा क्या है?**
     - **क्यों हो रहा है?**
     - **राजनीतिक प्रभाव क्या पड़ेगा?**
     - **मूल समाचार/X लिंक** सब विस्तार से दिखेगा।

2. **अभी तुरंत नया डेटा स्कैन करने के लिए:**
   - [`run_scan_now.bat`](run_scan_now.bat) पर डबल क्लिक करें। यह तुरंत लाइव मीडिया से ताजा खबरें फेच करके डैशबोर्ड को अपडेट कर देगा।

## 📱 2. टेलीग्राम पर हर घंटे अलर्ट कैसे पाएं? (2 मिनट सेटअप)

1. **Telegram खोलें** और सर्च करें: `@BotFather`
2. उसे `/newbot` भेजें और अपने बॉट का नाम दें (जैसे: `UttarakhandNewsAlertBot`)।
3. BotFather आपको एक **HTTP API Token** देगा (उदा: `7123456789:ABCdefGhIjk...`)।
4. अब Telegram पर सर्च करें: `@userinfobot` और उसे `/start` भेजें। यह आपको आपकी **Id** (उदा: `123456789`) दे देगा।
5. अब अपने बॉट के चैट में जाकर एक बार `/start` दबा दें ताकि बॉट आपको मैसेज भेज सके।
6. बस! अब अपने कंप्यूटर पर एनवायरनमेंट वेरिएबल सेट करें या `monitor.py` में लाइन 28 और 29 पर ये भर दें:
   ```python
   TELEGRAM_BOT_TOKEN = "आपका_टोकन"
   TELEGRAM_CHAT_ID = "आपकी_आईडी"
   ```

## ☁️ 3. लैपटॉप बंद होने पर भी 24x7 ऑटोमेशन कैसे चलेगा? (100% मुफ़्त)

यदि आपका लैपटॉप बंद है, तो आपका लोकल कंप्यूटर कोई कोड नहीं चला सकता। इसलिए इसे **GitHub Actions (Cloud)** पर चलाया जाता है, जो **100% फ्री** है और किसी सर्वर की जरूरत नहीं होती।

### स्टेप्स (5 मिनट का काम):
1. [GitHub.com](https://github.com) पर फ्री अकाउंट बनाएं।
2. **New Repository** बनाएं (नाम दें: `uttarakhand-political-radar`), इसे **Private** रखें।
3. इस पूरे फ़ोल्डर (`D:\Google-Dowanlod\Uttarakhand_Political_Monitor`) की सभी फाइलें उस रिपॉजिटरी में अपलोड (Push) कर दें।
4. GitHub Repo की **Settings** > **Secrets and variables** > **Actions** में जाएं और **New repository secret** जोड़ें:
   - Name: `TELEGRAM_BOT_TOKEN` | Value: (आपका टेलीग्राम टोकन)
   - Name: `TELEGRAM_CHAT_ID` | Value: (आपकी चैट आईडी)
5. GitHub Repo की **Settings** > **Actions** > **General** में नीचे स्क्रॉल करके **Workflow permissions** को **Read and write permissions** पर टिक करके Save करें।

### जादू:
- अब आपका लैपटॉप बंद रहे, आप सो रहे हों या कहीं यात्रा कर रहे हों—GitHub का क्लाउड सर्वर **हर घंटे अपने आप** स्क्रिप्ट चलाएगा।
- नया मुद्दा या विरोध आते ही आपके **मोबाइल पर तुरंत टेलीग्राम नोटिफिकेशन** आ जाएगा!
- GitHub Pages ऑन करने पर आप अपने मोबाइल पर कहीं भी लाइव डैशबोर्ड का लिंक खोलकर पूरा ब्योरा देख सकते हैं।
